# PasS Wine Fix

Wine上でPasS起動中にこのソフトウェアを実行することで、ツールバーが1段欠けている状況を改善します。

このソフトウェアを使用しなくても、起動時に引数リストに開きたいファイルを指定することでも、問題を回避できるようです。
